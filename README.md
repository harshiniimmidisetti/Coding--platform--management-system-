# Coding Platform Management System

## 📌 Project Overview

The **Coding Platform Management System** is a console-based C++ application designed to manage coding activities for **Students, Teachers, and Admins**.

The system provides features such as user management, coding problems, assignments, coding contests, student progress tracking, and coding platform progress.

## 🚀 Features

### 👨‍💼 Admin Module
- Admin login
- View all students
- View all teachers
- Manage users
- Manage coding problems
- Manage assignments
- Manage coding contests
- View student and teacher information

### 👨‍🏫 Teacher Module
- Teacher login
- View teacher details
- Create assignments
- View assignments
- Create coding contests
- View coding contests
- View student progress
- View coding platform progress

### 👩‍🎓 Student Module
- Student login
- View student details
- View coding problems
- Solve coding problems
- View assignments
- Complete assignments
- Participate in coding contests
- Track scores and completed activities
- Update coding platform progress

### 🌐 Coding Platforms
The system allows students to maintain their progress on popular coding platforms:

- LeetCode
- CodeChef
- HackerRank
- GeeksforGeeks
- Codeforces

Students can also track their active coding days.

## ▶️ How to Run

### Using Dev-C++

1. Open **Dev-C++**.
2. Open `main.cpp`.
3. Compile the program.
4. Run the program.
5. Select Admin, Teacher, or Student from the main menu.

### Using g++

```bash
g++ main.cpp -o coding_platform
```

Run:

```bash
./coding_platform
```

## 🎯 Objective

The main objective of this project is to create a simple coding management system where students can practice coding, complete assignments, participate in contests, and track their progress while teachers and admins can manage and monitor the activities.
